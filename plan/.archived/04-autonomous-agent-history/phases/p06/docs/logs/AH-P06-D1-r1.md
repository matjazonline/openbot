### Clarifications before first gate
Pressure uses one1536 retained-payload soft ceiling (no hidden hysteresis flag); each bounded pass expires only eligible rows above it, while the hard2048 admission limit protects pins/load bursts. Native expiry eligibility checks the actual count/age/recent-window condition as well as ownership, not a caller-supplied maintenance flag. Current payload flags/digests/level facts are rechecked after payload fetch; changed/expired data is projected as restricted/expired or a controlled read conflict, never advertised as an exact stale reconstruction.
