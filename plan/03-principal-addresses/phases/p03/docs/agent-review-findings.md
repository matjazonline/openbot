Implement that at this same inbound gate instead of looking up wire From; admission must see the resulting exact canonical agent author. This is an explicit existing decision obligation, not a third finding. A verified agent's normal team/grant authority and a platform notice's narrowly authenticated exception are distinct.
- Evidence retained: [static source excerpts](logs/D1-R1-reviewer-source.md). No future principal-notice implementation was exercised; this is a source-derived gate finding.
- Instruction lesson: when a private platform producer changes target kind, trace both the initial write authorization and asynchronous source reauthorization.
