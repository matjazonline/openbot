## Decisions and invariants

1. Preserve both accepted ancestries, Plan03 producer 3fceb7d3 and main d543787f, in the pending merge. Native MCP remains a real private workflow publication and worker-owned action with immutable provenance. Plan02 roles and principal targets remain available on all shared paths.
2. Extend main's existing application-controlled RowLocks (Wait/NoWait) through the responsible shared authorization helpers. Existing ordinary callers retain Wait. Native ingress, pre-body authentication and live effect validation retain NoWait at every newly shared account/company/association/selected-agent lock edge. Use the same SQL/validation as ordinary calls; no unlocked fallback or alternative authorization path. SQL lock contention remains ServiceUnavailable and whole-transaction rollback; retry may succeed after release.
3. Keep Plan02 purpose-specific account discovery and one sorted, bounded, deduplicated account union before company locks. Add NoWait support to that owner instead of retaining main's superseded all-policy-reviewer prelocker. Native workflow continuation uses the Effect purpose, preserving real actor/requester identities and post-company revalidation. Reply/dispatch/message purposes retain their current exact sources and bounds. No new recipient account is acquired after company ownership.
4. Use the sealed Plan02 agent_for_step selector for authored agent or role selectors. Thread RowLocks through its exact captured ownership/role/revision query and the selected-agent reader, so native continuation never waits while retaining sealed-role and exact-use checks. Do not replace role selectors with the pre-roles agent-only implementation.
5. Represent every native source association using the existing AssociationColumns codec (channel_id, principal_id, thread_id). SessionAssociation::Conversation still carries only its tenant-local conversation UUID; production lookup derives its exact desk/principal target. Workflow sessions copy all three columns and clamp the original knowledge ceiling. Native live checks authorize that exact association using NoWait. No NULL desk may become company scope.
6. Append principal_id to native_mcp_calls as the historical counterpart of channel_id; extend its association shape check and immutable identity tuple. Populate it from AssociationColumns. The ledger retains historical association identifiers through retirement just as it already retains desk/thread IDs; do not introduce a new live authority or deletion pin on retired ledger rows. workflow_runs retains the existing tenant-scoped association FKs and native call/run provenance pins. Extend native_mcp_witness to compare principal_id as well as desk/thread against its run; do not change lifetime, ownership, cancellation, recovery, ceiling or maintenance protocols.
7. Schema conflicts split through function bodies sharing a common tail. Reconstruct each side's complete appended DDL before concatenation; preserve all triggers/guards, rather than concatenate half-functions. Agent open_to_public and native_permissions remain independent persisted settings across write/read/UI/test surfaces.
