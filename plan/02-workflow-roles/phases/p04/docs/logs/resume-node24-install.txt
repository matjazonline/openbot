==> Caveats
==> node@24
node@24 is keg-only, which means it was not symlinked into /opt/homebrew,
because this is an alternate version of another formula.

If you need to have node@24 first in your PATH, run:
  printf '%s\n' export\ PATH\=/opt/homebrew/opt/node@24/bin:\$PATH >> ~/.zshrc

For compilers to find node@24 you may need to set:
  export LDFLAGS=-L/opt/homebrew/opt/node@24/lib
  export CPPFLAGS=-I/opt/homebrew/opt/node@24/include

The following node@24 executables are shadowed by linked node commands in /opt/homebrew/bin:
node
Running these by name will not invoke the version provided by this formula.
Run `brew link node@24` to switch the active version to this keg.
Disable this behaviour by setting `HOMEBREW_NO_PATH_SHADOW_CHECK=1`.
Hide these hints with `HOMEBREW_NO_ENV_HINTS=1` (see `man brew`).
