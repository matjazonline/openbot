Validate the effective choice against the discovered native provider capabilities. Saving a profile with an agent must not reject an unused fallback permission choice.

Hosted ModelOnly/Tools publication/use explicitly requires a configured, offered model before admission; model absence cannot become a placeholder or late provider failure. Agent library copy, draft persistence, authoring API/forms, active-state/published summaries and immutable definition validation all carry native permissions. Nullable model summaries clearly mean the local execution profile chooses the native model.

Native agent admission uses the active published revision under the same source/grant locking conventions as agent publication. Freeze the exact immutable revision and effective execution selection before workflow approval. Existing workflow continuation reuses the existing session's captured agent revision and execution selection, even if profile/active revision changed before continuation. Replay of an already admitted idempotency key precedes any new profile/active-revision selection.
