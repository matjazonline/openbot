+## Decided
+
+The user resolved the Plan06 README/01B.4 conflict: a procedure with active bindings
+is managed by managers of ANY unit with a current active binding. The recorded
+creating department governs only when no active binding exists. Publishing does
+not require authority over every existing binding; creating/moving a binding still
+requires authority over its actual target unit.
+
+Creation commands retain the destination workflow identity. If that same-company
+definition already exists, its current management authority applies before any
+collision or replay result. Only actual absence uses the creating unit.
+
+## Tried and ruled out
+
+Always using the recorded department contradicts the user's chosen binding rule.
+Identity-free creation authority exposes another unit's existing definition via
+conflicts or repeated template-copy keys; independent D3 review found that gap.
+
+## Watch out
+
+Use the current binding configuration/version, excluding inactive and historical
+revisions. Recheck current target authority on template-copy conflict replay, even
+when the original creator still manages its former department. Keep configuration
+management separate from conversation View and current authenticated provenance.

+// Captures only preparation; all decisive refusals below call the real PostgreSQL writer.
+#[async_trait::async_trait]
+impl WorkflowDefinitions for Capture {
+    async fn draft(
+        &self,
+        c: CompanyId,
+        w: WorkflowId,
+    ) -> crate::app_error::AppResult<Option<DraftState>> {
+        self.p.draft(c, w).await
+    }
+    async fn publication(
+        &self,
+        c: CompanyId,
+        k: &IdempotencyKey,
+    ) -> crate::app_error::AppResult<Option<PublishedCommand>> {
+        self.p.publication(c, k).await
+    }
+    async fn selectable_version(
+        &self,
+        c: CompanyId,
+        v: VersionId,
+    ) -> crate::app_error::AppResult<Option<Arc<PublishedBundle>>> {
+        self.p.selectable_version(c, v).await
+    }
+    async fn save_draft(&self, command: PreparedDraft) -> crate::app_error::AppResult<()> {
+        *self.draft.lock().unwrap() = Some(command);
+        Ok(())
+    }
+    async fn publish(
+        &self,
+        command: PreparedPublication,
+    ) -> crate::app_error::AppResult<Arc<PublishedBundle>> {
+        let bundle = command.command().bundle.clone();
+        *self.published.lock().unwrap() = Some(command);
+        Ok(bundle)
+    }

+/// second waiting on that exact backend, then release the first to commit in the proved order.
+pub(crate) async fn competing_writes<A, B>(
+    pool: &PgPool,
+    table: WriteBarrier,
+    first: impl std::future::Future<Output = A>,
+    second: impl std::future::Future<Output = B>,
+) -> CompetingWrites<A, B> {

+        .execute(&mut *barrier)
+        .await

+        .fetch_one(&mut *barrier)
+        .await
+        .unwrap();
+    let second = async {
+        wait_until_blocked_by(pool, blocker).await;
+        second.await
+    };
+    let release = async {
+        let writer = wait_until_blocked_by(pool, blocker).await;
+        wait_until_blocked_by(pool, writer).await;
+        barrier.commit().await.unwrap();
+    };
+    let (first, second, ()) = tokio::join!(first, second, release);
+    CompetingWrites { first, second }
