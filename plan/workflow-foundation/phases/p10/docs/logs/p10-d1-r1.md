identity: the immediate key rejects before the deferred historical-xid diagnostic. Change the
command identity: no matching authentic scheduled command; create one through the owner: current
witness and binding are created atomically. No current owner erases a binding while retaining its
command. Parent/child/review/message/retry additions introduce no unused authentic historical tuple.
This is a bounded obstruction over supported owners, not a universal impossibility claim over
arbitrary malicious SQL/DDL. We must not substitute reference-table coverage for the exact public
historical-witness diagnostic, fabricate protected history or loosen the schema to create a test.

independently reviewed obstruction. Rerun existing A layered test/catalog/public wrong-scope and
ordinal controls; add behavioral supported-service/provider safety integration. Do not claim the
